# FitLife

Sistema da academia FitLife desenvolvido em Java aplicando POO.


## Conceitos aplicados
- Classes e objetos
- Encapsulamento (atributos privados, getters e validação)
- Herança e polimorfismo (Plano, PlanoMensal, PlanoPremium)
- Classe abstrata (Plano)
- Relacionamentos (Cliente e Plano: associação; Cliente e Treino: composição)
- Tratamento de exceções
- Testes com JUnit 5

## Como executar
1. Requisitos: Java 17+ e IntelliJ IDEA
2. Abra a pasta do projeto no IntelliJ
3. Execute a classe `Main`
4. Para os testes: adicione a biblioteca JUnit 5 ao projeto (Alt+Enter sobre `@Test` → Add 'JUnit5.x' to classpath) e execute as classes de teste
